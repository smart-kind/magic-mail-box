宿主 Demo — 消息中心管理（多用户通信测试）

连接设置

设置保存在本浏览器 localStorage。跨域调用需在 Stalwart 开启 usePermissiveCors（Settings › Network › HTTP › Security），否则浏览器会拦截请求。 消息中心开发模式地址一般为 http://localhost:5173，构建后为 ../message-center/dist/index.html。

测试用户

批量创建 demo001@域名 ~ demo100@域名，密码规则 Demo001!Mc7 ~ Demo100!Mc7。 已存在的用户会被跳过（幂等，可重复点击）。

消息中心

通过 URL 参数 ?username=<邮箱>&password=<密码> 传入当前选中用户凭证，消息中心启动时用该参数完成 JMAP Basic Auth 自动登录。 多开几个浏览器标签页、各选不同用户，即可模拟多人互发消息。 注意：以 file:// 直接打开本页时，创建用户等 JMAP 功能可用， 但浏览器会拦截 iframe 内 file:// 构建产物的 JS/CSS； 建议在 minimal-web/ 下起一个静态服务（如 python3 -m http.server）再访问 /host-demo/， 或将消息中心地址指向 vite 开发服务器（http://localhost:5173）。
